# CINESCAPE demo script (under 3 minutes)

1. Open the home screen and introduce CINESCAPE as an original, TV-first entertainment discovery concept.
2. Use the arrow keys or D-pad to move across different show cards. Point out the immediate focus change, water extinguish ripple on the previous card, and ignition glow on the new card.
3. Show how the backdrop atmosphere and palette adapt to the focused title.
4. Open a title's details, review the synopsis and metadata, and return to browsing.
5. Open category browsing and search; demonstrate My List add/remove.
6. Close by explaining that this repository is a browser prototype and that Fire TV/Vega package verification is a separate target-device step.

Do not state that commercial media streams or that the app has been tested on a physical Fire TV unless that is true.
